# Changelog

Mudanças relevantes do projeto são registradas neste arquivo.

## v0.1.0

Primeiro baseline público versionado do Observatório de Combustíveis Brasil.

Principais componentes incluídos:

- pipeline de ingestão e validação dos dados oficiais da ANP;
- camadas separadas para agregados oficiais e preços por posto;
- rastreabilidade por manifesto e SHA-256;
- modelos estrela e carga PostgreSQL;
- KPIs, notebook, relatório web e especificação para Power BI;
- testes automatizados, cobertura mínima e integração PostgreSQL na CI;
- smoke periódico das fontes oficiais;
- documentação técnica e fluxo de contribuição externa.

Detalhes: [docs/releases/v0.1.0.md](docs/releases/v0.1.0.md).
