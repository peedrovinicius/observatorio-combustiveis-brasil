# Suporte

## Antes de abrir uma solicitação

Consulte primeiro:

- o README para visão geral e execução;
- `docs/fontes.md` para origem dos dados;
- `docs/metodologia.md` para regras analíticas;
- `docs/modelo-dados.md` para os grãos e o modelo dimensional;
- `docs/execucao.md` para o fluxo local;
- `docs/testes.md` para validações automatizadas.

## Problemas

Use o formulário **Relatar problema** para erros de ingestão, qualidade, SQL, PostgreSQL, relatório, Power BI ou documentação.

Sempre que possível, informe fonte, produto, unidade de medida, período, localidade e etapa do pipeline.

## Melhorias

Use o formulário **Propor melhoria** para sugestões técnicas, analíticas ou de documentação.

Mudanças de fonte, granularidade, unidade, KPI ou regra analítica devem declarar explicitamente o impacto metodológico.

## Segurança

Não publique vulnerabilidades ainda não corrigidas em issues. Siga [SECURITY.md](SECURITY.md).

## Limites

Este repositório não fornece:

- suporte oficial da ANP;
- aconselhamento financeiro ou comercial;
- garantia de atualização em tempo real;
- interpretação de sinal estatístico como prova de irregularidade.
